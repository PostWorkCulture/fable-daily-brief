`YYYY-MM-DD | COUNTRY/PLACE | topic keywords | headline as published`

RULES FOR THE daily-briefs-refresh TASK:
- READ THIS FILE BEFORE RESEARCHING the Fact of the Day, not after.
- NEVER reuse a fact that appears anywhere in this list, no matter how long ago.
- NEVER reuse a COUNTRY/PLACE listed in the last 60 entries.
- NEVER reuse a TOPIC ANGLE listed in the last 30 entries (e.g. landlocked/enclave geography,
  time zones, hemispheres, internet domains, place-name oddities) — vary the *kind* of fact too,
  not just the country.
- APPEND the new entry in the same run, before the git push, and commit it with the briefs.
- If this file is missing locally, restore it from the repo copy
  (`fact-history.md` in PostWorkCulture/fable-daily-brief) before choosing a fact.
